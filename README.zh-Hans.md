Vible 把你的声音变成干净、纠错、翻译好的文字——**在任何应用里**，快到与思绪同步。本地模型在 Apple Silicon 上带来速度与隐私；想要时,一键切换即可调用云端 GPU 的强大算力。按住热键、开口说、松手——Vible 便会转写、纠正语法、翻译，甚至还能读给你听。

---

## ✨ 亮点

- ⚡ **与思绪同速** — 按住 `⌃⌘`、开口说、松手。本地 Whisper 即时转写，润色好的文字直接粘贴到你所在的任意应用。
- 🧹 **自动语法润色** — 每段转写落地前都会先被清理：标点、大小写、口头禅（"嗯""呃""那个"）统统消失。
- 🌍 **实时翻译，20+ 语言** — 用一种语言说，输出另一种语言的文字。双向对话模式让你实时来回交流。
- ⌘ **双击 `⌘C`，随处翻译** — 在任意应用里选中文本，连按两下 `⌘C`，弹窗便就地翻译——可复制、朗读，或直接替换你选中的内容。
- 🗣️ **自然文本转语音 + 声音克隆** — 用录音棚级的嗓音朗读任何内容，或录 30 秒，让 Vible 用*你自己的*声音读给你听。
- 🪶 **默认本地运行** — 本地 **MLX + ONNX** 模型在 Apple Silicon 上运行。飞快、可离线、隐私无忧——你的音频无需离开 Mac。
- ☁️ **想用云端就用云端** — 一键启用 GPU 加持的模型：无需下载、无需预热，更丰富的神经网络嗓音。
- 🔒 **私密加密** — 不开启云端，就什么都不会上传。本地与传输中的数据均已加密；你的语音和文字绝不出售、共享，也绝不用于训练。
- 🍎 **已签名并公证** — 为 Apple Silicon 打造，由 **Algohash Inc.** 签名、经 Apple 公证——打开时没有任何安全警告。

## 🎙️ 语音闭环——一个热键，四项超能力

按住键、开口说、松手。整个交互就这么简单。

| | 步骤 | 会发生什么 |
|---|---|---|
| 1 | **采集** | 在任何地方按住 `⌃⌘` 开口说——实时波形显示它正在聆听。 |
| 2 | **转写** | 本地 Whisper 即时把语音变成原始文字，全在设备上完成。 |
| 3 | **润色** | 语法、大小写、口头禅一次过清理干净。 |
| 4 | **翻译 / 朗读** | 可选翻译，随后自动粘贴到你的应用——或朗读出来。 |

> 你说话的速度约是打字的 3 倍。Vible 让这份速度在 Mac 的每一个文本框里都能派上用场。

## ⌘ 随时随地，就地翻译

无需开窗口，也不用粘贴：

1. **选中** 任意应用里的任意文本——邮件、Slack、PDF、浏览器。
2. **双击 `⌘C`** — 要快。Vible 会捕捉到这次复制，弹窗就在你光标处跳出来。
3. **选择语言与语气** — 源语言自动识别；选好目标语言和语气（*正式*、*自然*，或*带发音*），然后**复制**、**朗读**出来，或就地**替换**你选中的内容。

Vible **全程本地运行**——语音转文字与文本转语音全部通过 **MLX 与 ONNX** 在 Apple Silicon 上执行。无需联网、没有服务器、无从泄露——哪怕关掉 Wi-Fi 也照样私密。

- ✅ 完全离线可用
- ✅ 什么都不上传——永远不会（除非你启用云端）
- ✅ 本地**与**传输中均加密（TLS）

需要极致吞吐量和最丰富的神经网络嗓音？一键切换到 **GPU 云端**——即时合成，无需预热。无论哪种方式，你的数据都经过加密，且绝不用于训练。

## ❓ 常见问题

<details>
<summary><b>它真的在本地设备上运行吗？</b></summary>

是的。默认的语音转文字与 TTS 模型通过 MLX 和 ONNX 在 Apple Silicon 上本地运行——飞快且可离线。云端 GPU 需自行选择开启，想要更丰富的嗓音或极致速度时，一键切换即可。
</details>

<details>
<summary><b>支持哪些 Mac？</b></summary>

任何搭载 Apple Silicon（M1 或更新）、运行 macOS 12 或更高版本的 Mac。应用已签名并公证。已提供签名并公证的 Windows 10/11 版本；Linux 版本仍在规划中。
</details>

<details>
<summary><b>Vible 在每个应用里都能用吗？</b></summary>

能——它是全系统的。在任意文本框（邮件、Slack、你的编辑器、浏览器）里按住热键，润色好的结果就会粘贴到你光标所在处。
</details>

<details>
<summary><b>它能用我自己的声音说话吗？</b></summary>

在 Studio 套餐下，你可以录一小段样本，Vible 便会用你声音的克隆读回文本，同时还提供标准与高级神经网络嗓音。
</details>
